DÉTECTEUR CRYPTO H24 - OPTIONS DE LANCEMENT
===========================================

Serveur moteur et interface graphique séparés
---------------------------------------------
  1. Dans la console du moteur, définir le même jeton secret que pour l'IHM :
        $env:PREDICT_TOKEN = "votre-jeton-secret-de-16-caracteres-minimum"
        .\predict.exe --serve
        Ou avec Cargo, depuis le dossier du projet :
           cargo run -- --serve

     Le serveur écoute par défaut sur 0.0.0.0:8765 et démarre en temps réel.
     Adresse personnalisée :
           .\predict.exe --serve --listen 0.0.0.0:8765
     Avec Cargo :
           cargo run -- --serve --listen 0.0.0.0:8765

     2. Sur le même ordinateur, dans une autre console, ou par double-clic si
        PREDICT_TOKEN est déjà défini :
           .\predict.exe
        Ou avec Cargo, dans une autre console :
           cargo run

     L'IHM se connecte par défaut à 127.0.0.1:8765.
     Pour un moteur sur un autre ordinateur :
           $env:PREDICT_TOKEN = "le-meme-jeton-secret"
           .\predict.exe --connect 192.168.1.10:8765
     Avec Cargo :
           cargo run -- --connect 192.168.1.10:8765

  L'IHM peut changer de mode et piloter le moteur. Fermer l'IHM ne l'arrête pas ;
  seul Ctrl+C dans la console du serveur arrête le moteur.

Mode local : moteur et IHM ensemble
-----------------------------------
  .\predict.exe --local
  Avec Cargo, depuis le dossier du projet :
        cargo run -- --local

  Le moteur et l'IHM démarrent dans la même application. Fermer la fenêtre de
  l'IHM arrête également le moteur et ses flux.

Analyse console autonome (sans serveur)
---------------------------------------
  predict.exe --console [--mode <MODE>] [options]

  --console            Lance en mode console, sans interface graphique
  --local              Lance moteur et IHM ensemble ; fermeture = arrêt des deux
  --mode <MODE>        temps-reel (défaut) | simulation | periode | fichier
  --debut AAAA-MM-JJ   Date de début           (requis avec --mode periode)
  --fin AAAA-MM-JJ     Date de fin, incluse    (requis avec --mode periode)
  --fichier <chemin>   Fichier JSON de bougies (requis avec --mode fichier)
  --config <chemin>    Fichier de configuration (défaut : config.toml)
  -h, --help           Affiche l'aide
  -V, --version        Affiche la version

  --mode, --debut, --fin et --fichier ne fonctionnent qu'avec --console.
  --serve              Lance le moteur contrôlable par l'IHM
  --listen <IP:PORT>   Adresse d'écoute (défaut : 0.0.0.0:8765, avec --serve)
  --connect <IP:PORT>  Adresse du serveur pour l'IHM (défaut : 127.0.0.1:8765)
  PREDICT_TOKEN        Jeton partagé requis par le serveur et l'IHM

Exemples
--------
  Suivi en direct sur Binance (Ctrl+C pour arrêter) :
        predict.exe --console

  Simulation locale (prix fictifs) :
        predict.exe --console --mode simulation

  Test sur une période (télécharge les données Binance, les enregistre dans
  historique_<début>_<fin>.json, puis affiche les alertes) :
        predict.exe --console --mode periode --debut 2026-04-01 --fin 2026-04-03

  Rejeu d'un fichier JSON enregistré :
        predict.exe --console --mode fichier --fichier historique_2026-04-01_2026-04-03.json

  Autre fichier de configuration :
        predict.exe --console --config autre.toml

Remarques
---------
  - config.toml est lu dans le dossier courant : lancez l'exe depuis le dossier
    qui le contient (un double-clic le fait automatiquement).
  - Le jeton TCP n'est pas chiffré : utilisez un réseau privé de confiance ou un VPN.
  - Les modes periode et fichier se terminent seuls ; le code de sortie est
    différent de 0 en cas d'erreur.
  - L'IHM nécessite qu'un serveur soit déjà démarré et que PREDICT_TOKEN soit défini.
